Core ERP Modules

Everything runs per tenant on its own database, gated by granular module.action permissions.

📦Master Data

Products (variants, images, batch/expiry/serial tracking), category hierarchy with typed attributes, brands, units, warehouses with zone→rack→shelf→bin locations, suppliers, customers, price lists.

🛒Purchasing

Purchase orders with approval workflow, goods receipt (partial & over-receipt guarded), put-away to bin locations, batch/expiry/serial capture, supplier purchase history & exposure.

💰Sales & Invoicing

Sales orders: draft → confirm (credit + stock checks) → deliver with atomic stock-out and auto invoicing; multi-mode payments with partial/paid rollups and overpay guard.

📊Inventory Engine

Immutable stock ledger with weighted-average costing, stock adjustments (reason-coded), inter-warehouse transfers with in-transit state, cycle counts, returns inward, low-stock alerts.

🏢B2B Customer Portal

Customers log in (Sanctum tokens or SMS OTP) to place B2B orders that flow through a sales-order approval pipeline.

🌐E-commerce Integrations

Unified marketplace-connector framework for 7 platforms — channel-order inbox that imports into ERP sales orders.

💳Payment Gateway

Config-driven gateway drivers with shareable /pay/{token} links; transactions reconcile into accounting vouchers.

🧾GST Compliance

GSTIN validation, HSN master, e-invoice & e-way bill generation (offline mode + GSP seam), GSTR-2 and GSTN JSON exports.

🏷️Barcode & Labels

Barcode, QR, sticker and price-tag label templates with a print picker; scanning and RFID support in receiving flows.

🤖AI Insights & Assistant

Statistical sales forecasting, demand & low-stock prediction, purchase suggestions, plus a bilingual chat/voice assistant for ERP search (local or LLM-backed narration).

🔍Global Search

Meilisearch-powered omni-search across products, customers and invoices — one shared index per model, filtered by tenant.

⚙️Workflow Builder

IF/THEN/ELSE automation engine fired from model events — approvals, notifications and field updates without code.

📱SMS & Notifications

Driver-based SMS service (log/MSG91) with templated sends and hashed OTPs, powering portal OTP login and alerts.

📥Data Import / Export

Generic Excel/CSV/JSON importer, demo-data generator, client-side CSV export and print on every listing screen.

🧭Dynamic Menus & UX

DB-driven navigation with favorites & recents, dashboard widgets, dark mode, responsive layout throughout.

Multi-Tenant Architecture

Built on stancl/tenancy: the central database holds tenants, domains, plans, subscriptions and platform users; each signed-up company gets its own MySQL database, resolved by subdomain before auth runs.

HostContextServes
localhost Central Signup & email verification, tenant provisioning, plan catalogue, Razorpay webhooks
{tenant}.localhost Tenant The full ERP — login and all business APIs against that tenant's database
/platform SaaS owner Platform portal: billing & subscriptions, tenant management & suspension, ops (health, queues, backups, logs, feature flags)

🚀Self-Serve Onboarding

Register → verify e-mail code → queued job provisions the database, seeds roles & masters, creates the owner admin and starts a 14-day trial.

📈Plans & Limits

Starter ₹999 / Growth ₹2,999 / Enterprise. Plan-limit middleware returns HTTP 402 with an upgrade prompt; lapsed tenants go read-only, operator suspension hard-locks.

🔐Shared-Infra Isolation

One shared queue, cache, search index and file bucket — every job, cache key, index document and folder is tenant-scoped by convention.

Quick Start (Local · WAMP)

Default admin: admin@sims.test / password — demo tenant at demo1.localhost:5173.

Backend :8000

cd backend
php artisan migrate --seed
php artisan serve
# required — runs tenant provisioning
php artisan queue:work

Frontend :5173

cd frontend
npm install
npm run dev
# proxies /api -> 127.0.0.1:8000
# signup: http://localhost:5173
# tenant: http://{sub}.localhost:5173
⚠️ Dev notes: mail uses the log driver (verification codes echo back as dev_code locally); queues/cache run on the database driver; *.localhost resolves to 127.0.0.1 with no hosts-file edits.
