# Enterprise SaaS ERP - Import & Export Logistics Module

## Overview

This module integrates Import, Export, Freight, Customs, Warehouse,
Inventory, Sales, Purchase, Manufacturing and Accounts into a single
workflow.

## Features

-   Active Import Shipments
-   Active Export Shipments
-   ETA / ETD
-   Container Status
-   Shipment Profit
-   Pending Documents
-   Pending Customs Clearance
-   Logistics Expenses
